### gpt 추천
#### 1️⃣ 기본 원칙 (절대 깨지면 안 되는 것)

- 클립 데이터는 **시간 기준으로만 저장**
    
    - `startTime`
        
    - `duration`
        
- 픽셀 값은 **렌더링 시에만 계산**
    
- Timeline DOM 크기 변화는 **데이터에 영향 없음**
    
- 시간 ↔ 픽셀 변환은 **단일 기준값(pxPerSecond)**만 사용
    

---

#### 2️⃣ 전역 기준값 정의

- `pxPerSecond` 상태로 관리
    
- 기본값 예: `100`
    
- Zoom in / out 시 이 값만 변경
    

---

#### 3️⃣ 데이터 모델 설계

- Clip 구조
    
    - `id`
        
    - `trackId`
        
    - `startTime`
        
    - `duration`
        
- Timeline 상태
    
    - `clips[]`
        
    - `pxPerSecond`
        
    - `totalDuration` (렌더링용)
        

---

#### 4️⃣ Timeline 컨테이너 구조

- 외부 컨테이너
    
    - `position: relative`
        
    - `overflow-x: auto`
        
- 내부 콘텐츠 레이어
    
    - `width = totalDuration * pxPerSecond`
        
- Track Row
    
    - `position: relative`
        
- Clip
    
    - `position: absolute`
        

---

#### 5️⃣ Source → Timeline Drag & Drop

- dnd-kit 사용
    
- Timeline 전체를 droppable로 등록
    
- Drag 중:
    
    - 마우스 `clientX` 수집
        
    - timeline `getBoundingClientRect()`
        
    - `scrollLeft` 반영
        
    - `x → time` 변환
        
    - `snap(time)`
        
    - ghost clip 위치 업데이트
        
- Drop 시:
    
    - `startTime = previewTime`
        
    - clip 데이터 생성
        
    - ghost 제거
        

---

#### 6️⃣ Drag 중 시간 계산 공식

- `x = clientX - timelineLeft + scrollLeft`
    
- `time = x / pxPerSecond`
    
- 음수 방지
    
- 스냅 적용
    

---

#### 7️⃣ Ghost Clip 처리

- 실제 clip과 분리된 상태
    
- 드래그 중에만 렌더링
    
- `pointer-events: none`
    
- opacity 적용
    

---

#### 8️⃣ Timeline 내부 Clip 이동

- dnd-kit 사용 ❌
    
- mouse 이벤트 직접 처리
    
- `onMouseDown`:
    
    - startX 기록
        
    - startTime 기록
        
- `onMouseMove`:
    
    - deltaPx 계산
        
    - deltaTime = deltaPx / pxPerSecond
        
    - `startTime + deltaTime`
        
- `onMouseUp`:
    
    - clip 데이터 업데이트 확정
        

---

#### 9️⃣ Clip 리사이즈

- 좌/우 resize handle 제공
    
- 오른쪽 핸들:
    
    - duration만 변경
        
- 왼쪽 핸들:
    
    - startTime + duration 함께 변경
        
- 최소 duration 제한
    
- 스냅 적용
    

---

#### 🔟 Timeline Resize 대응

- ResizeObserver로 timeline width 감지
    
- width 값은:
    
    - auto-scroll 판단
        
    - playhead 중앙 유지
        
    - UI 계산용
        
- 시간 계산에는 사용 ❌
    

---

#### 1️⃣1️⃣ Zoom 처리

- 버튼 / 휠 이벤트로 zoom 제어
    
- `pxPerSecond`만 변경
    
- 모든 clip 렌더링 자동 반영
    

---

#### 1️⃣2️⃣ Scroll 관리

- playhead 기준 중앙 유지 옵션
    
- resize 전/후 scroll 비율 유지 옵션
    
- drag 중 가장자리 auto-scroll 구현
    

---

#### 1️⃣3️⃣ Track 계산

- 마우스 Y좌표 기준
    
- `trackIndex = floor((clientY - timelineTop) / trackHeight)`
    
- clip 이동 시 trackId 변경
    

---

#### 1️⃣4️⃣ 충돌 처리 (선택)

- Drop 시:
    
    - 겹치면 금지 / 덮어쓰기 / ripple 중 선택
        
- Drag 중:
    
    - 충돌 영역 시각화 가능
        

---

#### 1️⃣5️⃣ Undo / Redo 대비

- Drop / DragEnd / ResizeEnd 시점만
    
    - history stack push
        
- Drag 중 state 변경 기록 ❌
    

---

#### 1️⃣6️⃣ 성능 기준

- Drag 중 state 최소화
    
- requestAnimationFrame 사용 가능
    
- clip 수 많으면 virtual rendering 고려
