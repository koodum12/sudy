
#### 서브 에이전트와의 차이

| __         | 서브에이전트           | 에이전트 팀                    |
| ---------- | ---------------- | ------------------------- |
| **소통 방식**  | 결과만 메인에게 보고      | 팀원끼리 직접 대화                |
| **조율**     | 메인 에이전트가 전부 관리   | 공유 태스크 리스트로 자율 조율         |
| **적합한 작업** | 결과만 중요한 단순 작업    | 토론과 협업이 필요한 복잡한 작업        |
| **토큰 비용**  | 낮음 (결과만 요약해서 전달) | 높음 (각 팀원이 독립 Claude 인스턴스) |
