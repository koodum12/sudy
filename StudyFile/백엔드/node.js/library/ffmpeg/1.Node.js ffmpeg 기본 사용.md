### ffmpeg 이미지 추출(영상에서)


동영상에서 이미지를 추출하려면 Video 객체에서 **fnExtractFrameToJPG** 함수를 호출하면 됨

기본적으로 3개의 파라미터 필요
1) 이미지를 저장할 디렉토리 위치
2) 이미지를 추출할 옵션
3) 콜백 함수
	
###### ex code)
```js
const ffmpeg = require('ffmpeg')

const targetMP4File = '디렉토리/sample.mp4'
const to_img_file = '저장할 디렉토리'
new ffmpeg(targetMP4File, (err, video) => {
	if(!err){
		console.log(video.metadate);
		
		// 이미지 추출 옵션
		let img_option = {
			start_time : 0,
			frame_rate : 1,
			number : video.metadate.duration.seconds,
			file_name : 'file_%t_%s'			
		}
		
		// 동영상에서 이미지 추출
		video.fnExtractFrameToJPG(to_img_file, img_option, (error, files))=>{
			if(!error) console.log('finish imgs')
		}
		
	}
})
```

시작 시간 = start_time
프레임 비율 = frame_rate
종료 시간 = number

%t = 형식
%s = 생성된 순서



### 오디오 파일 분리
오디오를 분리하는 함수는 **fnExtractSoundToMp3**라는 함수를 사용

2개의 파라미터 필요
1) 오디오 파일 위치 + 파일명
2) 콜백 함수

###### ex code)
```js
const ffmpeg = require('ffmpeg')

const targetMP4File = '디렉토리/sample.mp4' // 이미지 파일
const to_audio_file = '디렉토리/sample.mp3' // 오디오 파일


new ffmpeg(targetMP4File, (err,video) =>{
	if(!err){
		//동영상에서 이미지 추출하기(비동기)
		video.fnExtractSoundToMp3(to_audio_file, (error, file) =>{
			if(!error) console.log("finish audio!")
		})
	}
})
```
